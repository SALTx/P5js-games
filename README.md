# P5js-games

A collection of mini games and projects built with [p5.js](https://p5js.org/), made to learn game development and open to community contributions.

## About
Ill fill this in next time, but its a repo where anyone can contribute their p5 projects. its a work in progress , but hopefully I can get more people creating cute little projects in p5js and get better at codign along the way :) 

## Repository structure
​```
projects/                 # one folder per project
p5js project template/    # starter template for new projects 
Playground/               # scratch space for experiments 
​```

## Running a project
Open the project's `index.html` in a browser, or use VS Code's Live Server.

## Contributing
1. Fork and branch
2. Copy the template into `projects/<name>/`
3. Fill in the project README
4. Open a pull request
